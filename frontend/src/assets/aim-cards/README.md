# AIM 五周年完整卡面素材

此目录是登录／注册页卡牌轮播的唯一素材目录，只收录用户提供的「AIM 五周年扑克计划」中的完整卡面。机器人独立线稿、PSD 和没有完整卡面的目录不参与轮播。

- 完整卡面：32 张。
- 编码：WebP，质量 85，宽度 640 px，保持原比例（约 640 × 977）。
- 原始卡面 PNG 合计：160,563,124 字节（约 153 MiB）。
- 网页素材合计：3,005,210 字节（约 2.87 MiB），缩减 98.1%。
- 文件名统一为「花色-点数.webp」，按黑桃、红桃、梅花、方片及点数排列。
- `manifest.json` 记录卡牌身份、来源相对路径、尺寸与压缩前后体积；`index.ts` 将所有完整卡面导入为 Vite 管理的资源 URL。

重新导入（从仓库根目录运行，需要 Pillow）：

```bash
backend/venv/bin/python frontend/scripts/import-aim-cards.py '/path/to/AIM 五周年扑克计划'
```

原始素材目录保持不变，便于以后重新导出。不要将 PNG / PSD 原稿或机器人独立线稿放入此目录。轮播仅按需挂载当前与相邻图片，避免首屏下载全部卡面。
